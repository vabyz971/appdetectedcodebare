##  Getting Started

###  Prerequisites Linux 

- **Python**: `version 3.10`
- **libzbar0**
- **python3-tk**

###  Installation

Build the project from source:

1. Clone the appdetectedcodebare repository:
```sh
❯ git clone https://github.com/vabyz971/appdetectedcodebare
```

2. Navigate to the project directory:
```sh
❯ cd appdetectedcodebare
```

3. To run the project, execute the following command:
```sh
❯ ./run.sh
```
